## NC-NN: <title>

| | |
|---|---|
| Found | <date>, <where: report, run, review, pull request> |
| What | What is wrong, with the figures or file that show it |
| Results affected | Which results, reports or samples, or none and why |
| Immediate action | What was done at once to stop wrong results being used |
| Cause | The cause found, or "not found" with what was looked at |
| Corrective action | What was changed so it does not happen again, and through which procedure (a change under SOP-01 section 9 if the pipeline is edited) |
| Effectiveness | How the action was shown to work, on which data, or "not yet checked" |
| Risk register | Risk IDs affected; a new risk is added if none fits |
| Status | open, or closed <date> |
